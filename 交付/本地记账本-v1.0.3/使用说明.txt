# 本地记账本 · 使用说明

一款**完全离线**的个人记账软件：不联网、不注册、不上传，所有数据只保存在你自己的电脑上。

## 一、怎么开始使用

### 方式 A：桌面版（推荐）

双击 `本地记账本-v1.0.3-便携版.exe` 即可打开，**无需安装**。

- 数据自动保存在本机（见下文“数据存在哪里”），每次改动自动保存。
- 如果 Windows 弹出“已保护你的电脑”（SmartScreen，因为软件未购买数字签名证书），请点 **更多信息 → 仍要运行**。这是所有个人制作的小软件都会遇到的安全提示，程序本身不含任何联网或上传行为。

### 方式 B：网页备用版

如果某些电脑策略严格、无法运行 exe，双击 `app` 文件夹里的 `index.html`，会直接用浏览器打开同一套界面。

- 数据保存在浏览器内置数据库中（同样只在本地）。建议定期点右上角下载按钮「导出备份」。
- 推荐使用 Chrome / Edge；清除浏览器数据会导致记录丢失，请先导出备份。

## 二、功能一览

- **学校收支**：为学校记账量身定做的界面，一屏显示收入合计、支出合计、结余；支出明细自动按「未报销 / 已报销 / 已开票」分组并小计，点一下状态标签即可切换报销状态。
- **总览**：一个画面同时看到「本月预算、已花费、剩余、钱花在了哪里（分类圆环图）」，另有最近交易和分类预算进度。
- **记一笔**：支出 / 收入 / 转账三种类型，可选分类、账户、日期，可写备注。
- **明细**：按天分组的全部记录，支持按类型、分类、账户筛选和关键词搜索，可编辑、删除。
- **统计**：近 6 个月收支趋势、本月每日支出、分类排行、月度概览。
- **预算**：设置每月总预算和每个分类的每月限额（自动按月生效），超额会有红色提醒。
- **账户**：现金、微信、支付宝、银行卡等账户余额自动汇总为净资产。
- **分类**：内置常用分类，可自行新增、改名、换图标换颜色、设置分类预算。
- **外观**：浅色 / 深色 / 跟随系统三种主题，货币符号可切换。
- **备份**：一键导出 JSON 备份；导入时与现有数据合并、按编号去重，并自动补齐缺失的月份预算（不覆盖已有数据）。

## 三、数据存在哪里（桌面版）

- 数据文件：`C:\Users\你的用户名\AppData\Roaming\local-jizhang\data.json`
  （软件「设置」页里能看到确切路径，点“复制路径”即可）
- 自动备份：同目录下 `backups` 文件夹，每次保存都会保留最近 30 份历史副本。

换电脑迁移：在旧电脑上「导出备份」，把 JSON 文件发给新电脑，再在新电脑上「导入 / 合并数据」。

## 四、快捷键

- `Ctrl + N`：快速记一笔
- `Esc`：关闭弹窗

## 五、常见问题

1. **记录会不会丢失？** 桌面版每改一次自动写盘，另有 30 份自动备份；建议每月手动导出一份 JSON。
2. **能多个设备同步吗？** 不能，本软件刻意保持纯本地、无云端，保护隐私。多设备之间用「导出 / 导入」手动迁移。
3. **杀毒软件误报怎么办？** 程序未做商业签名，个别杀软可能提示；加入信任列表即可。你也可以改用网页备用版，完全规避。
